Confirmation bridge: To manage state
We connect a component to the Confirmation bridge.
OnInitialized we subscribe a method to the bridge
like so
ConfirmationBridge.Instance.ConfirmationChanged += OnConfirmationChanged;

and unsub like so in a method called Dispose()
ConfirmationBridge.Instance.ConfirmationChanged -= OnConfirmationChanged;

The subscribed method must take a bool arg and use that to change state
then InvokeAsync(StateHasChanged);

Lastly connect the confirmationBridge to the OnClicked method in the xaml.cs

ConfirmationBridge.Instance.PublishResult(answer);

we got answer from 
bool answer = await DisplayAlertAsync(
	"Confirm Action",
	"Do you want to continue?",
	"Yes",
	"No");
